# MW2-Campaign-SpecOps-Mod-Menu-PS4

# MAG Cheats – Campaign & Special Ops

> ⚠️ Intended for **offline single-player / Special Ops only**. Do not use in multiplayer or online.

---

## ✨ Features

### On by default in every mission
| Mod | State |
|---|---|
| God Mode | ✅ ON |
| Unlimited Ammo | ✅ ON |
| No Recoil | ✅ ON |
| FOV | ✅ 90 |

Mods are **re-applied automatically** on every new mission, checkpoint or restart (the game resets them each time). A check runs every second to put the FOV back to the right value and restart the God Mode / ammo loops if they stopped.

---

## 🎮 Controls

| Combo | **R1 +** | **L1 +** |
|---|---|---|
| **↑ Up** | God Mode ON/OFF | Complete Special Op |
| **→ Right** | Unlimited Ammo ON/OFF | Unlock All Missions (Veteran) |
| **← Left** | No Recoil ON/OFF | All Special Ops 3 Stars |
| **↓ Down** | Change FOV (65 → 80 → 90 → 100 → 110) | All Intel (45) |

Notes:
- **L1** shortcuts (progression / unlocks) are reserved for **player 1**.
- *Complete Special Op* only works inside a Special Ops mission (a message is shown otherwise).
- An on-screen message confirms each action (ON / OFF).

## How To Install ?

---
1. Download ZIP
2. Take MAG_Cheats_CP_SO folder drag and drop it in /data/01cedric/mw2/mods/
3. Launch mw2, go in mods options, turn ON this folder

├── maps/

## 🔧 Installation

1. Copy `_wwsp.gsc` and `_wwsp_opts.gsc` into the `maps/` folder of your mod build, replacing the existing files.
3. Launch the game and load a mission: the mods turn on about 3 seconds after loading.

---

## ⚠️ Known notes

- **Restart Mission**: if you use Restart Mission mods are disabled and don't laod you need to quit and restart your mission
